I'm a **Cybersecurity Researcher** focused on **web security, reconnaissance and offensive security**.

My approach combines practical security testing, attack-surface discovery and continuous research to understand how applications can be attacked — and how they can be better secured.

> **Explore. Understand. Test. Improve.**
